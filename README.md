# ritchcassidy-site

One-page site for Ritch Cassidy (cassidycountry.com), hosted on GitHub Pages.

- `index.html`: the whole site (HTML, CSS and a few lines of JS in one file)
- `assets/img/`: photos and icons
- `CNAME`: tells GitHub Pages to serve the site at cassidycountry.com
